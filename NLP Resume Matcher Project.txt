🔹 TF-IDF broken into parts
1️⃣ Term Frequency (TF)

How often does a word appear in a document?

Example (resume):

java java spring boot
Word	Count
java	2
spring	1
boot	1

More occurrences → more importance within that document.

2️⃣ Inverse Document Frequency (IDF)

How rare is the word across ALL documents?

java appears in many resumes → less special

kubernetes appears in few resumes → very special

Formula (conceptually):

IDF(word) = log(total documents / documents containing word)

So:

Rare words → higher score

Common words → lower score

3️⃣ TF × IDF = TF-IDF

Final weight:

TF-IDF = TF * IDF

So:

Frequent + rare = high weight

Frequent + common = low weight

🔹 What problem TF-IDF solves (very important)

Without TF-IDF:

Every word has equal weight

“java” == “the” (bad!)

With TF-IDF:

Skills dominate

Noise disappears

Matching improves dramatically
